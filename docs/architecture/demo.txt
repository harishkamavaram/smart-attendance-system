======================================================================================
Client requests a protected resource.
Gateway checks the accessToken.
If the access token is valid → forward the request.
If the access token is missing or expired → return 401 Unauthorized.
The client then calls /auth/refresh.
The Auth Service validates the refreshToken, issues new cookies, and returns success.
The client retries the original request.

                        ├── Generate new refresh token (if rotating)
                        └── Set new HttpOnly cookies

            Client retries original request
